# OptiProfiler Scores 与结论

## 结论

Primary full-factorial screen 已完成。当前建议继续使用
`(c_x,c_tau)=(1,1)`，不执行 local refinement，也不修改 production rule：

- `c_x=1` 在两个 checkpoints 都明显优于更小的 `c_x`；
- `(1,1)` 在 `200*N` 和 `500*N` 都明显优于 accelerated unit-step baseline；
- `(1,2)` 是 full-17 common pool 中唯一在两个 aggregate scores 上都略高于 `(1,1)`
  的 challenger，但优势只有 `8.12e-5` 和 `2.70e-4`，不足以视为 material
  improvement；
- formal shortlist 仍是 `(1,1)` 与 `(1,2)`，因此“暂时保留 `(1,1)`”不等于已经
  formal close。

## Experiment basis 与 provenance

- 122 个 unconstrained S2MPJ problems，dimensions `6:50`；
- feature：untransformed `plain`；
- 三个 acceleration switches 全部为 `true`；
- 每个 identity 只运行一次到 `500*N`；
- `200*N` 使用同一 run 的逐 problem history prefix，并独立重算 targets；
- history profiles 覆盖 `tau=1e-1,...,1e-10`；
- OptiProfiler commit：`e8a4c44f555eafaddc3530b68c54fe1a78459cd9`；
- machine-readable pairwise values：`pairwise_results.mat` 与 `pairwise_results.txt`；
- direct-comparison curves/scores：`cx1_ctau1_vs_unit_200n.mat` 与
  `cx1_ctau1_vs_unit_500n.mat`；
- full-17 common-pool scores remain recorded in the tables above; the auxiliary full-pool
  PDFs and machine-readable curve dumps were removed from the working tree after review。
